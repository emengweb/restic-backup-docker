v2.0.6在每账号元数据增加必需global_grant_option布尔值，原生导入后仅撤销源不存在而目标额外存在的全局转授权；保留原账号认证、完整PROXY五元组和数据库/表/列/例程授权。原存在的全局转授权若未恢复则明确失败，不擅自广授。修复前后窄范围授权集合必须相同，最后再复验全局布尔及PROXY精确集。缺少新metadata旧Maria归档failclosed，需要重新做完整备份；不删除旧仓库或历史。

本版本包含前述每host认证保护、显式私有映射、新卷seed账号精确清理与Compose文档修正。文件/lite和PG路径不借Maria修复改变能力边界。真实合成用例保留raw SHOW CREATE USER/SHOW GRANTS全账号等价guard，不放宽为“能启动即可”；每实例生产仍需完整新备份、冻结所有写入者、新卷恢复、实际应用身份和回滚边界。
